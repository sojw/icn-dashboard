# 인천공항 라이브

지금 인천공항에서 뜨고 내리는 비행기를 그냥 보는 화면.
아무 목적이 없다. 점수도, 미션도, 실패도 없다.

**<https://sojw.github.io/icn-dashboard/>**

- 데이터: 공공데이터포털 [인천국제공항공사_항공기 운항 현황 상세 조회](https://www.data.go.kr/data/15140153/openapi.do)
- 10분마다 갱신된다. 화면에는 앞뒤 6시간치가 실려 있어 그 사이는 브라우저가 시계로 메운다.

## 배속에 대해

왼쪽 위 버튼으로 **실시간 / 4배속 / 8배속**을 바꾼다. 기본은 4배속이다.

인천공항은 실제로 **평균 80초에 한 번** 뜨거나 내린다. 실시간으로 두면 정직하지만
화면이 한산하다. 배속은 같은 실제 운항 기록을 빨리 돌려 보는 것이고, 그때 화면의
시각은 **벽시계가 아니라 재생 중인 시각**이다. 버튼에 그렇게 적혀 있다.

**실시간(1배속)일 때는 화면의 착륙이 지금 실제로 일어나는 착륙이다.**

## 그 밖에

- **공항 배치는 실제다.** 활주로 4본·터미널·유도로·주기장 221곳이 OpenStreetMap
  의 실제 도형이고, 비행기는 자기 주기장 번호의 그 자리에 선다.
  편명·시각·게이트·기종·주기장 번호도 전부 실제 값이다.
- 코드셰어는 마스터 편명으로 접었다. 안 접으면 같은 비행기가 두세 대로 겹쳐 보인다.
- 카메라는 지금 이착륙 중인 비행기를 따라간다. 드래그하면 10초간 직접 볼 수 있다.
- 비행기를 누르면 편명·노선·게이트·기종이 나온다.
